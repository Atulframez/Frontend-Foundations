Experiment 17 • Technical Lab Report (Menu Bar, DIVs & IFRAMEs)

This experiment satisfies all 3 sub-requirements: a persistent responsive menu bar, structured content partitions using <div>, embedded sandboxed sub-documents using <iframe>, and fluid responsive adaptability across viewports.

a. Responsive Menu Bar

Constructed with semantic <nav>, <ul>, and <li> with CSS dropdowns, collapsing into a slide drawer via media queries and JS toggle.

b. DIV vs IFRAME Partitioning

DIVs provide semantic, DOM-accessible page divisions within the host document. IFRAMEs isolate separate HTML browsing contexts with independent CSS and JS execution.

c. Responsive Architecture

Utilizes CSS Flexbox, modern CSS Grid with minmax(320px, 1fr), and media query breakpoints (900px and 600px) ensuring fluid mobile and desktop layouts.
