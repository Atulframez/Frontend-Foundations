Category 1 User Action & Interaction Pseudo-Classes

1. Pointer Hover

:hover

Applies styling when the user hovers over an element with a pointing device.

button:hover { transform: translateY(-4px); }

2. Element Activation

:active

Matches while the mouse button is actively held down (press down).

button:active { transform: translateY(6px); }

3. Input Focus

:focus

Triggers when an interactive field accepts keyboard or mouse focus.

input:focus { border-color: #38bdf8; }

4. Ancestor Focus

:focus-within

Highlights the parent wrapper if ANY internal descendant has focus.

Experiment 18 • Technical Lab Report (CSS Pseudo-Classes Architecture)

CSS Pseudo-classes allow developers to dynamically style elements based on their runtime state, user interactions, or structural position in the DOM hierarchy without injecting redundant inline classes or DOM mutation scripts.

1. Dynamic State Selectors

Pseudo-classes like :hover, :active, and :focus listen directly to browser input events, enabling fluid reactive UI styling with zero JavaScript overhead.

2. Tree Structural Selectors

Patterns like :nth-child(even), :first-child, and :not() compute document tree positions mathematically, perfect for tables and alternating lists.

3. Pure CSS State Machines

By leveraging :checked and :target, developers can implement accessible toggles, modals, and tabs purely through declarative CSS rules.

4. Specificity & Performance

Pseudo-classes contribute 0,1,0 to CSS specificity (equivalent to a class selector), and are heavily accelerated by modern GPU styling pipelines.
