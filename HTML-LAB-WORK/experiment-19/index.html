add_customer.php (PHP Prepared Statement & PDO) 
<?php
/**
 * Experiment 19: PHP Script to Add New Record in CUSTOMER Database
 * Course: Advanced Web Technology (CSIT248) - Amity University Noida
 */

$host = 'localhost';
$user = 'root';
$pass = ''; // Default XAMPP password
$db   = 'customer_db';

try {
    // 1. Establish PDO Connection
    $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass, [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
    ]);

    // 2. Handle Form POST Submission
    if ($_SERVER['REQUEST_METHOD'] === 'POST') {
        $name    = trim($_POST['customer_name'] ?? '');
        $email   = trim($_POST['email'] ?? '');
        $phone   = trim($_POST['phone'] ?? '');
        $address = trim($_POST['address'] ?? '');
        $city    = trim($_POST['city'] ?? '');

        // Validation
        if (empty($name) || empty($email) || empty($phone) || empty($address) || empty($city)) {
            die("Error: All fields are required.");
        }

        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            die("Error: Invalid email format.");
        }

        // 3. Prepare and Execute INSERT query
        $sql = "INSERT INTO customers (customer_name, email, phone, address, city) 
                VALUES (:name, :email, :phone, :address, :city)";
        $stmt = $pdo->prepare($sql);
        $stmt->execute([
            ':name'    => $name,
            ':email'   => $email,
            ':phone'   => $phone,
            ':address' => $address,
            ':city'    => $city
        ]);

        $insertedId = $pdo->lastInsertId();
        echo "Customer successfully created with ID: #" . $insertedId;
    }
} catch (PDOException $e) {
    if ($e->getCode() == 23000) {
        echo "Error: A customer with this email already exists.";
    } else {
        echo "Database Connection Error: " . $e->getMessage();
    }
}
?>
customer_schema.sql (MySQL Table DDL & Seed Data) 
-- Experiment 19: Database Schema for CUSTOMER Database
CREATE DATABASE IF NOT EXISTS customer_db;
USE customer_db;

-- Create CUSTOMERS Table
CREATE TABLE IF NOT EXISTS customers (
    customer_id INT AUTO_INCREMENT PRIMARY KEY,
    customer_name VARCHAR(100) NOT NULL,
    email VARCHAR(120) NOT NULL UNIQUE,
    phone VARCHAR(20) NOT NULL,
    address TEXT NOT NULL,
    city VARCHAR(60) NOT NULL,
    registered_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Experiment 19: Academic Lab Manual

1. Aim

To write a robust PHP script that connects to MySQL, accepts customer details via an interactive HTML form, sanitizes and validates input data, and adds a new record to the customers table using prepared statements to prevent SQL Injection attacks.

2. Core Concepts

  • PDO (PHP Data Objects): A lightweight, consistent interface for accessing databases in PHP. Offers prepared statements, transactions, and robust error modes.
  • SQL Injection Prevention: Direct string interpolation allows attackers to manipulate queries. Prepared statements separate the SQL template from data parameters, guaranteeing immunity from SQL injection.
  • Unique Constraint Handling: The email column has a UNIQUE index; attempting to insert duplicate emails triggers error code 23000, which is caught and gracefully handled.

3. Algorithm

  1. Create MySQL database customer_db and table customers.
  2. Render an HTML form with input fields for Name, Email, Phone, City, and Address.
  3. Capture user form submission via HTTP POST.
  4. Validate that required fields are not empty and verify email syntax via filter_var().
  5. Establish a PDO connection with exception error mode enabled.
  6. Prepare the SQL INSERT INTO customers ... query with bound placeholders.
  7. Execute the query passing sanitized input values.
  8. Fetch the auto-incremented primary key using lastInsertId() and inform the user.
  9. Query all records using SELECT * FROM customers and display in an HTML table.
