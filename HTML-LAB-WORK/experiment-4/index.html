Demonstration of HTML5 Image Mapping

Interactive demonstration of the HTML <map> and <area> tags using rectangular (rect), circular (circle), and polygonal (poly) clickable hotspot regions.

HTML5 Implementation Code Breakdown

<!-- Associating Image with Map using usemap -->
<img src="workstation.svg" width="800" height="500" alt="Workstation" usemap="#workstation-map">

<!-- Client-Side Image Map Definition -->
<map name="workstation-map">
  <!-- 1. RECTANGLE: coords="x1,y1, x2,y2" -->
  <area shape="rect" coords="220,60,580,280" href="#monitor" alt="Monitor">
  <area shape="rect" coords="240,330,560,420" href="#keyboard" alt="Keyboard">

  <!-- 2. CIRCLE: coords="centerX, centerY, radius" -->
  <area shape="circle" coords="630,375,35" href="#mouse" alt="Mouse">
  <area shape="circle" coords="150,360,35" href="#coffee" alt="Coffee Mug">

  <!-- 3. POLYGON: coords="x1,y1, x2,y2, x3,y3, ... xn,yn" -->
  <area shape="poly" coords="640,70,760,70,760,300,640,300" href="#tower" alt="PC Tower">
  <area shape="poly" coords="60,110,120,70,170,110,170,220,120,250,60,220" href="#headphones" alt="Headphones">
</map>
