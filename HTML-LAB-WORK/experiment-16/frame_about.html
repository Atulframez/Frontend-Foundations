About HTML <frameset> and Percentage Rows / Columns

Key Frameset Attributes

  • rows="val1%, val2%, ...": Divides the browser vertically into horizontal bands according to the given percentage splits (e.g., 20%, 70%, 10%).
  • cols="val1%, val2%, ...": Divides the browser or a parent frame horizontally into vertical columns (e.g., 25%, 75%).
  • target="...": Specifies which named frame receives the destination document when a hyperlink is activated.
  • noresize: Prevents users from dragging and altering the designated frame boundaries.
  • scrolling="auto|yes|no": Controls whether scrollbars appear inside the frame.
