student_lookup.php (PHP Server Parser) 
<?php
/**
 * Experiment 13: Student Marks Retrieval from Server XML
 * Advanced Web Technology (CSIT248) - Sem VI IT
 */

$xmlFile = 'students.xml';
$enrollment = trim($_POST['enrollment_no'] ?? $_GET['enrollment_no'] ?? '');

if (empty($enrollment)) {
    die("<p>Please enter an Enrollment Number.</p>");
}

if (!file_exists($xmlFile)) {
    die("<p>Error: XML Document not found on server.</p>");
}

// Load and parse XML document using SimpleXML
$xml = simplexml_load_file($xmlFile);
$found = null;

// Iterate and match student enrollment number
foreach ($xml->student as $student) {
    if (strcasecmp((string)$student->enrollment_no, $enrollment) === 0) {
        $found = $student;
        break;
    }
}

if ($found) {
    echo "<h2>Student Name: " . htmlspecialchars($found->name) . "</h2>";
    echo "<p>Enrollment No: " . htmlspecialchars($found->enrollment_no) . "</p>";
    echo "<p>Semester: " . htmlspecialchars($found->semester) . "</p>";
    echo "<table border='1' cellpadding='8'>";
    echo "<tr><th>Code</th><th>Subject</th><th>Marks</th></tr>";
    
    foreach ($found->marks->subject as $subject) {
        echo "<tr>";
        echo "<td>" . htmlspecialchars($subject['code']) . "</td>";
        echo "<td>" . htmlspecialchars($subject['name']) . "</td>";
        echo "<td>" . htmlspecialchars($subject) . " / " . htmlspecialchars($subject['max']) . "</td>";
        echo "</tr>";
    }
    echo "</table>";
    
    echo "<h3>Total Marks: " . htmlspecialchars($found->total_marks) . " / 500</h3>";
    echo "<h3>Percentage: " . htmlspecialchars($found->percentage) . "%</h3>";
    echo "<h3>Grade: " . htmlspecialchars($found->grade) . "</h3>";
} else {
    echo "<p style='color:red;'>No record found for Enrollment: " . htmlspecialchars($enrollment) . "</p>";
}
?>

Experiment 13: Academic Lab Manual

1. Aim of the Experiment

To create a structured XML document containing records of 10 students of SEM VI IT (including Enrollment Number, Marks obtained in 5 subjects, Total Marks, and Aggregate Percentage) saved on the web server, and develop a server-side processing script that accepts an Enrollment Number as user input and returns individual subject marks, total marks, and percentage by querying the XML database.

2. Theoretical Foundations

  • XML (eXtensible Markup Language): A standard text-based markup language for encoding documents in a format that is both human-readable and machine-readable, widely used for platform-independent data exchange.
  • DOM (Document Object Model) & SimpleXML: PHP provides native extensions like SimpleXML and DOMDocument to load, parse, traverse, and query XML documents using tree-based and XPath representations.
  • XPath Expression: Syntax used to navigate and search through nodes and attributes in an XML document (e.g., //student[enrollment_no='IT2023001']).

3. Algorithm

  1. Construct students.xml with root <students_database> and 10 child <student> elements with 5 subject scores.
  2. Prompt user via an HTML form to supply their unique enrollment_no.
  3. On submission, the server receives the input via HTTP POST/GET.
  4. Validate the input and check whether students.xml exists on the server filesystem.
  5. Load the XML tree using simplexml_load_file().
  6. Traverse the student elements comparing the enrollment number using case-insensitive string comparison.
  7. If a match is discovered, extract subject marks, total marks, percentage, and grade, then render a formatted tabular response.
  8. If no match exists, return an informative error status.
