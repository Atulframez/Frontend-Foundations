## 🛠️ Technology Stack

- **Frontend:** Semantic HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, Dark UI), Vanilla JavaScript (ES6+).
- **Backend / Database:** PHP 8.x, XML / SimpleXML / DOMDocument, MySQL (PDO Prepared Statements).
- **Typography:** Inter, Fira Code, Outfit (Google Fonts).
- **Hosting / CI:** Netlify ([atulanand-web-tech-labwork.netlify.app](https://atulanand-web-tech-labwork.netlify.app/)).
