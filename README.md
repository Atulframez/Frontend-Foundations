## ⚡ Highlighted PHP, XML & MySQL Experiments (Inside `HTML-LAB-WORK/`)

### [Experiment 13: Student XML Database & Server-Side Lookup](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-13/)
- **Problem Statement:** Create an XML document of 10 students of SEM VI IT. Add their Enrollment No., marks obtained in 5 subjects, total marks, and percentage saved at the server. Write a program that accepts a student's Enrollment No. as input and returns their marks, total, and percentage by querying the server XML document.
- **Technologies:** XML, DOMParser, PHP SimpleXML / XPath.
- **Files:** [`students.xml`](./HTML-LAB-WORK/experiment-13/students.xml) &bull; [`student_lookup.php`](./HTML-LAB-WORK/experiment-13/student_lookup.php) &bull; [Live Demo](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-13/)

### [Experiment 19: Add New Record in CUSTOMER Database](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-19/)
- **Problem Statement:** Write a PHP Script to add a new record to the CUSTOMER database with input validation and prepared SQL statements.
- **Technologies:** PHP 8.x, MySQL, PDO Prepared Statements, SQL Injection Defense, Unique Constraint Handling.
- **Files:** [`customer_schema.sql`](./HTML-LAB-WORK/experiment-19/customer_schema.sql) &bull; [`add_customer.php`](./HTML-LAB-WORK/experiment-19/add_customer.php) &bull; [Live Demo](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-19/)

### [Experiment 20: Implementation of include( ) and require( )](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-20/)
- **Problem Statement:** Write a PHP Script to implement and demonstrate functions `include()` and `require()`.
- **Technologies:** Modular PHP Architecture, Error Severity Levels (`E_WARNING` vs `E_COMPILE_ERROR`), `include_once` / `require_once` re-declaration guards.
- **Files:** [`config.php`](./HTML-LAB-WORK/experiment-20/config.php) &bull; [`header.php`](./HTML-LAB-WORK/experiment-20/header.php) &bull; [`footer.php`](./HTML-LAB-WORK/experiment-20/footer.php) &bull; [`include_require_demo.php`](./HTML-LAB-WORK/experiment-20/include_require_demo.php) &bull; [Live Demo](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-20/)

### [Experiment 21: Demonstration of Array, String and Numeric Functions](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-21/)
- **Problem Statement:** Write a PHP Script to demonstrate array, string, and numeric functions.
- **Technologies:** Native PHP Standard Library (over 25 functions demonstrated with live parameters).
- **Files:** [`functions_demo.php`](./HTML-LAB-WORK/experiment-21/functions_demo.php) &bull; [Live Demo](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-21/)

### [Experiment 22: MySQL Commands Implementation (DELETE, ORDER BY, UPDATE)](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-22/)
- **Problem Statement:** Write a PHP Script to implement the following MySQL commands: a) `DELETE` b) `ORDER BY` c) `UPDATE`.
- **Technologies:** PHP PDO, Whitelist-based Column Sorting, DML Transactions, Real-time SQL Command Inspector.
- **Files:** [`schema.sql`](./HTML-LAB-WORK/experiment-22/schema.sql) &bull; [`mysql_crud_demo.php`](./HTML-LAB-WORK/experiment-22/mysql_crud_demo.php) &bull; [Live Demo](https://atulanand-web-tech-labwork.netlify.app/HTML-LAB-WORK/experiment-22/)

## 💻 Local Setup & Execution

### 1. View Static & Client-Side Interactive Pages
Clone the repository and open `index.html` directly in any modern browser:
```bash
git clone https://github.com/Atulframez/Frontend-Foundations.git
cd Frontend-Foundations
open index.html
```

### 2. Run PHP & MySQL Server Scripts (XAMPP / Apache)
1. Copy or clone the repository into your web server's root directory:
   - **XAMPP (Windows):** `C:\xampp\htdocs\Frontend-Foundations`
   - **XAMPP (macOS):** `/Applications/XAMPP/htdocs/Frontend-Foundations`
2. Start **Apache** and **MySQL** services in the XAMPP Control Panel.
3. Import the SQL schemas in phpMyAdmin or MySQL CLI:
   - For Exp 19: [`HTML-LAB-WORK/experiment-19/customer_schema.sql`](./HTML-LAB-WORK/experiment-19/customer_schema.sql)
   - For Exp 22: [`HTML-LAB-WORK/experiment-22/schema.sql`](./HTML-LAB-WORK/experiment-22/schema.sql)
4. Open your browser and navigate to:
   - Portfolio: `http://localhost/Frontend-Foundations/HTML-LAB-WORK/`
   - Student XML Lookup: `http://localhost/Frontend-Foundations/HTML-LAB-WORK/experiment-13/student_lookup.php`
   - Customer Database Manager: `http://localhost/Frontend-Foundations/HTML-LAB-WORK/experiment-19/add_customer.php`
   - Include/Require Demo: `http://localhost/Frontend-Foundations/HTML-LAB-WORK/experiment-20/include_require_demo.php`
   - PHP Functions Demo: `http://localhost/Frontend-Foundations/HTML-LAB-WORK/experiment-21/functions_demo.php`
   - MySQL Operations Workbench: `http://localhost/Frontend-Foundations/HTML-LAB-WORK/experiment-22/mysql_crud_demo.php`
