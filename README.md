## 🚀 Quick Launch: CSIT248 Lab Experiments

The **[`HTML-labwork/`](./HTML-labwork)** directory contains an interactive, web-based portfolio ([`HTML-labwork/index.html`](./HTML-labwork/index.html)) with ready-to-run experiments:

- **Exp 01–03**: Student Registration Forms, Semantic Bio Pages, and Academic Timetables
- **Exp 04–06**: Interactive Client-Side Image Maps, Ordered Lists, and Table Galleries
- **Exp 07–09**: JavaScript History Navigation, Frontend Form Validation, and Pure CSS Layouts
- **Exp 10–12**: DHTML Dynamic DOM Records, Computer Peripherals Catalog, and Hometown Web Showcase
- **Exp 13**: Student XML Database & Server-Side Lookup System (`SimpleXML` & `DOMParser`)
- **Exp 14–16**: Interactive Login Authentication, Web Tech Quiz Engine, and Percentage Frames
- **Exp 17–18**: Responsive DIV/IFRAME Navigation and CSS Pseudo-Classes Interactive Studio
- **Exp 19**: Add New Record in CUSTOMER Database (`PDO` & MySQL Prepared Statements)
- **Exp 20**: Implementation of `include()` vs `require()` Lifecycle and Error Handling
- **Exp 21**: Demonstration of 25+ PHP Array, String & Numeric Built-in Functions
- **Exp 22**: Implementation of MySQL Commands (`DELETE`, `ORDER BY`, `UPDATE`)
