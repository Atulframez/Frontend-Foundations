Experiment 20: Academic Lab Manual

1. Aim

To design and execute a modular PHP application demonstrating the implementation and comparative functional behavior of include() and require(), with specific focus on file dependency handling, error generation levels, and execution flow.

2. Viva-Voce Questions & Answers

Q1: What is the main difference between include() and require()?

Ans: When a file cannot be found, include() produces a warning (E_WARNING) and allows script execution to continue, whereas require() throws a fatal error (E_COMPILE_ERROR) and immediately halts the script.

Q2: When should require_once() be preferred over require()?

Ans: When including files that declare functions, classes, or database connections, to avoid fatal errors caused by duplicate declarations if the file is accidentally referenced multiple times.

Q3: Does include() return a value?

Ans: Yes, include() returns FALSE on failure and raises a warning. If the included file uses a return statement, the returned value is provided to the caller.
