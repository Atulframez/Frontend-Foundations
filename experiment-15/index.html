Experiment 15 • Technical Architecture & Calculation Algorithm

This experiment highlights dynamic client-side state manipulation using JavaScript objects, event listeners, array methods, and real-time score calculation algorithms without requiring external server calls.

1. State Data Structure

Questions are structured in an immutable array of objects storing stems, code snippets, multiple choices, correct indices, and explanation strings.

2. Score Algorithm

Calculates score using Total = (Correct × 4) - (Incorrect × 1). Computes accuracy percentage: (Correct / Attempted) × 100.

3. Real-Time Timer

Utilizes setInterval() to decrement a countdown timestamp and automatically triggers submission when remainingSeconds === 0.

4. Dynamic DOM Reconstruction

Re-renders option nodes dynamically on each navigation event, preserving state selections across the user response matrix.
